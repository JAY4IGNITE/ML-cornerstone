# Frontend Requirements

## Design Direction
Professional financial analytics interface:
- Minimal and clear
- Strong hierarchy
- Responsive
- Accessible contrast
- Consistent spacing and typography
- Avoid generic AI visuals and unnecessary decoration

## Pages
1. Overview Dashboard
2. Loan Risk Assessment
3. Prediction Result
4. Explainability
5. Model Performance
6. Dataset Quality
7. Model Information
8. Responsible Use and Limitations

## Result Display
Clearly separate:
- Default probability
- Risk score
- Risk band
- Model version
- Explanation
- Data limitations
- Disclaimer that this is not a lending decision

## UX States
Implement:
- Loading state
- Empty state
- Validation error state
- API failure state
- Successful result state
- Unsupported input state

## Accessibility
- Keyboard navigability
- Semantic HTML
- Visible focus states
- Adequate contrast
- Labels for every input
- Avoid color-only communication
